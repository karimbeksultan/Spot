# Data licenses

The raw OpenStreetMap responses and the normalized POI database contain © OpenStreetMap contributors data. They are made available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Attribution and applicable share-alike obligations must be retained when this database is redistributed. See [OpenStreetMap copyright](https://www.openstreetmap.org/copyright).

Wikidata structured facts and Wikimedia Commons structured metadata are CC0. Image copyright is separate from metadata: the actual photographs retain each file's individual license, author and source page recorded in `pois.json` and `photo-links.json`. No photograph bytes or map tiles are bundled in this directory. The interface loads small Commons thumbnails, and the user must preserve their attribution and license when redistributing images or adaptations.

The source database license is independent of the application's source-code license. Technical reports in this directory contain only source-collection outcomes, public POI coordinates and counts; they do not include user location history, prompts or service keys.
