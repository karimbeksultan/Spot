# Документация Spot

Spot помогает выбрать короткую прогулку по Астане: старт, доступное время, обязательные остановки и возвращение учитываются вместе. Приложение предназначено для жителей и гостей города; регистрация не требуется.

Пример: «Сначала кофе в кафе, затем парк. Есть 60 минут, нужно вернуться». Spot проверяет полный набор обязательных остановок. Если данных или времени недостаточно, интерфейс показывает уточнение, отсутствие совпадений или непроверенные варианты.
