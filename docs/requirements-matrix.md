# Соответствие первому треку

> Историческая матрица первоначального прототипа, сохранённая для истории. Ниже описаны прежний набор из 98 POI и тогдашняя готовность материалов. PDF впоследствии получен и изучен. Для действующего контракта см. [матрицу R2](REQUIREMENTS_MATRIX.md), для готовности сдачи — [актуальный checklist](SUBMISSION_CHECKLIST.md).

Матрица основана на предоставленной текстовой версии первого трека. Оригинальный PDF не доступен. «Реализовано» означает наличие функции в коде; фактические результаты запуска перечислены отдельно в [test-report.md](test-report.md).

|---|---|---|---|---|---|
| Концепция и аудитория | «Астана за твоё время», три пользовательских сценария | [concept.md](concept.md) | Сопоставление сценариев с доступными полями | Пользователь вводит время и старт | Нет исследования с реальными пользователями |

## Критерии жюри

Порядок из предоставленного текста: полезность и релевантность; контекст и адаптивность; объяснения; UX; креативность; этика и приватность; завершённость. Матрица показывает доказательства по этим направлениям, без заявлений об официальных весах или гарантированных баллах.
