# Фактическая проверка Spot

Дата: 16 октября 2026. Окружение: Windows, Node.js 24.16, npm 11.13, Chromium 156.0.8078.4 (Playwright 1.64.1), Next.js 16.4.2. Intel i5-10310U, 15,76 ГиБ RAM. ## Основной режим: реальные ответы

| Ввод | Результат | Задержка |
|---|---|---|
| «Я возле Mega Silk Way, есть 45 минут, хочу прогуляться и вернуться» | Аллея мира и согласия; настоящий пешеходный возврат; 40 минут с посещением и резервом | 33,5 с |
| «Я с ребёнком, есть час, хочу что-нибудь интересное неподалёку» | Реальная площадка из корпуса; полный план 53 минуты | 29,4 с |
| «Хочу кофе в тихом месте рядом, розетка обязательна» | Пустой результат; условие сохранено; генерация обоснованно пропущена | 3,1 с |
| «Хочу провести немного времени среди деревьев, без кафе» — ввод в Chromium | Аллея мира и согласия; без кафе; план 36 минут; `live`, `supabase-hybrid`, `ollama-validated` | 17,7 с |

Первые три запроса отправлялись последовательно через HTTP API с браузерным Origin; четвёртый — через форму интерфейса. В непустых ответах проверены существующие ID, факты и evidence из корпуса, границы времени и реальные пешеходные сегменты. Важное различие: факт посещения или фактическое время пешей прогулки не измерялись. Маршрут — оценка провайдера.

Маленькая Qwen3 0.6B отвечает на CPU. Наблюдаемая задержка 17,7–33,5 секунды для трёх непустых запросов не является нагрузочным benchmark. Выборка мала, независимой оценки полезности top-3 людьми нет.

## Набор из 18 запросов

`tests/evaluate-snapshot.ts` выполняет обычные, перефразированные, конфликтующие, пустые и недостоверные запросы к настоящему снимку. Проверяются ожидаемая пустота/непустота, ограничения, принадлежность evidence и отсутствие выдуманного маршрута. Все 18 прошли; p50 56 мс, p95 402 мс. Это **резервный режим без модели и маршрутизации**, его скорость не относится к live RAG. Полные входы и результаты сохранены в JSON.

## Браузер и воспроизведение

Тесты UI намеренно проверяют резерв при недоступной модели, используя настоящие данные Spot и доступную маршрутизацию. В первом терминале PowerShell:

```powershell
$env:OLLAMA_BASE_URL='http://127.0.0.1:1'
npm run build
npm start -- --port 3001
```

Во втором:

```powershell
npx playwright install chromium
$env:SPOT_BASE_URL='http://127.0.0.1:3001'
npm run test:e2e
```

`SPOT_BROWSER_PATH` необязателен: указывает полный путь к Chromium, если он установлен в другом месте. В этой среде использовался `work/browsers/chromium-1248/chrome-win64/chrome.exe`. Этот локальный binary не включён в архив исходников. macOS/Linux: задавайте те же переменные как `SPOT_BASE_URL=http://127.0.0.1:3001 npm run test:e2e`.

Для настоящего RAG откройте новый терминал (чтобы не наследовать адрес недоступной модели), запустите разрешённую локальную Ollama и `npm start`. Затем:

```powershell
$env:SPOT_BASE_URL='http://127.0.0.1:3000'
npm run eval:live
node scripts/verify-live-browser.mjs
```

Скрипты не имитируют модель, БД или маршрут. Live-проверка может завершиться ошибкой при отказе внешнего провайдера, строгом ответе модели или отсутствии настроек; это отражается в отчёте. Не запускайте её одновременно с тяжёлой сборкой на данном ноутбуке.

## Исправленные сбои

Первичные браузерные прогоны выявили неверный URL worker MapLibre, нулевую высоту карты, лишнее поле `name` в координатах формы, несовпадение loopback Origin, отклонение корректного thumbnail Wikimedia и неправильное декодирование Valhalla polyline6. Исправления проверены повторно. Три последующих падения относились к неоднозначному тестовому селектору alert (системный announcer Next.js и сообщение приложения); селектор уточнён, повтор прошёл. После review добавлены сброс прокрутки при открытии плана/карточки и сохранение нового времени в тексте запроса, чтобы замена места не возвращала старый бюджет. Финальный общий прогон: 12/12 за 1,9 минуты. После последнего изменения позиции камеры мобильный сценарий отдельно повторён: прошёл за 19,4 секунды; выбранный маркер проверяется над раскрытой карточкой.

## Безопасность и оставшиеся проверки

- `npm audit --omit=dev`: 0 уязвимостей production-зависимостей на момент установки. Полный audit: 5 high в цепочке инструментов ESLint (`fast-glob → micromatch → braces`). Совместимого исправления в проверенной актуальной версии не было; `audit fix --force` не применялся, поскольку предлагал откат основных инструментов. Это оставшийся риск dev-инструментов, а не устранённая проблема.
- `.env.local`, модели, runtime, browser binary и журналы игнорируются Git и исключены из архива. Привилегированный ключ Supabase не экспортировался. Приложение читает БД через publishable key на сервере. Поиск credential-паттернов в исходниках и `.next/static` дал 0 совпадений; конфигурация Supabase не обнаружена в клиентском bundle. Это ограниченная проверка характерных паттернов, а не формальный аудит безопасности.
- Геолокация запрашивается только по действию; история и координаты не пишутся в localStorage. Передачи в Supabase, routing и карты перечислены в privacy.md.
- Docker и альтернативная локальная Supabase не проверены. Offline-режим, нагрузочное испытание, реальная прогулка, screen reader и независимое пользовательское исследование не выполнены.
- YouTube, публикация GitHub и деплой не выполнялись. Подготовлен воспроизводимый сценарий записи с текстом выступления.

После проверки собственные серверы приложения и Ollama остановлены. На ноутбуке измерены 4,65 ГиБ свободной RAM из 15,76 и 59,94 ГиБ свободного диска C:. Во время live-прогона guard записал пик рабочего набора Ollama 835,7 МиБ и минимум свободной RAM 3,23 ГиБ; порог 1 ГиБ не пересекался. Эти значения относятся к конкретному сеансу.
