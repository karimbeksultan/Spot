# Проверки и сценарии

## Команды

```bash
npm run doctor
npm run verify
```

`verify` выполняет lint, TypeScript, unit-тесты, проверку данных, snapshot evaluation, evaluation cases, production build и smoke. Окружение изолирует платные провайдеры; реальные LLM/БД/маршрутизация этим прогоном не проверяются.

Браузерные проверки запускаются отдельно при работающем demo-сервере:

```bash
npx playwright install chromium
npm run demo
# В другом терминале:
npm run test:e2e
```

## Что проверяется

Полный зафиксированный протокол сценариев R2: [PDF](TEST_SCENARIOS_AND_LIMITATIONS.pdf) и [Markdown](TEST_SCENARIOS_AND_LIMITATIONS.md). Оба исходных файла сохранены без изменений; их исторические отметки не заменяют текущий статус CI.

| Сценарий | Ожидаемая граница |
| --- | --- |
| Кофе, затем парк, ограниченное время и возврат | Все обязательные этапы и общий бюджет; без silent partial success |
| Ресторан с заданной кухней | Тип и каждый cuisine-токен подтверждаются source evidence |
| Неизвестная обязательная розетка / цена | Unknown не проходит жёсткое условие |
| Продолжение диалога и изменение условий | Контекст обновляется; устаревший ответ не заменяет новый |
| Плановая дата и другое время устройства | Время Астаны UTC+5 сохраняется |
| Недоступный маршрутизатор | Варианты обозначены unverified, готовая линия и общая длительность не выдумываются |
| Ошибочные ID модели / невалидный ответ | Сервер отвергает неподтверждённые данные |
| Мобильный экран, клавиатура, фото и источники | Проверяемые действия и явные пустые/ошибочные состояния |

Историческая отдельная проверка локального Qwen и маршрутизации дала два полных плана (43/60 и 58/90 минут) и отказ в 40-минутном случае с возвратом: [receipt](../artifacts/verification/local-compound-r2-20261018/summary.json). Это три запроса на публичных точках, не исследование полезности и не обещание результата для любого старта.

## Известные ограничения проверки

`npm audit --omit=dev` сообщил 0 проблем; полный audit — 5 high в одной цепочке dev-зависимости [braces без опубликованного патча](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm). ESLint 9 достиг end-of-life; поддерживаемый переход зависит от plugin peers. Это открытые вопросы инструментов разработки.

Проверка исходников и достижимой истории не нашла подтверждённых ключей; совпадения оказались тестовыми значениями. Это ограниченный scan, не pentest. Независимая полезность с людьми, полная локализация и физическая доступность маршрутов не измерялись. Подробнее: [ограничения](limitations.md).
